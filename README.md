# Свет Веры

Telegram Mini App и бот для исламских знаний, времени намазов, дуа, Корана и персональных напоминаний.

## Требования

- Node.js 22.11.0 или новее;
- Telegram Bot Token;
- Polza AI API key для AI-помощника;
- публичный HTTPS URL приложения после деплоя.

## Локальный запуск

1. Скопируйте `.env.example` в `.env` и заполните секреты.
2. Установите зависимости: `npm install`.
3. Запустите приложение: `npm start`.

`glass.css` находится в `public/css/glass.css` и используется без изменений.
