  ТЕХНИЧЕСКОЕ ЗАДАНИЕ: ИСЛАМ МИНИ ПРИЛОЖЕНИЕ
  Telegram Mini App + Bot
═══════════════════════════════════════════════════════════════════════════════

ПРОЕКТ: Ислам Мини Апка — персональное и семейное приложение для исламских знаний

ЯЗЫК: Русский (основной), арабский (для сур и дуа)

ЦЕЛЕВАЯ АУДИТОРИЯ: Пользователь-мусульманин и его семья (мама, папа)

ТЕХНОЛОГИЧЕСКИЙ СТЕК (СТРОГО ОБЯЗАТЕЛЬНО):
- Frontend: Telegram Mini App (WebApp SDK)
- Backend: Node.js + Express
- База данных: SQLite (node:sqlite)
- Бот: Telegraf (Telegram Bot API)
- Планировщик: node-cron (для напоминаний о намазах)
- AI помощник: Polza AI API

  ДИЗАЙН И СТИЛЬ (КРИТИЧНО)
═══════════════════════════════════════════════════════════════════════════════

ЦВЕТОВАЯ СХЕМА (ОБЯЗАТЕЛЬНО):
- Основной цвет: Зелёный (#1B7A4A или аналогичный — цвет ислама)
- Акцентный цвет: Золотой (#D4AF37 или аналогичный)
- Фон: Тёмный (тёмно-серый или чёрный для контраста)
- Текст: Белый / светло-серый на тёмном фоне

ЭФФЕКТ ЖИДКОГО СТЕКЛА (КРИТИЧНО — ОБЯЗАТЕЛЬНО ИСПОЛЬЗОВАТЬ):
⚠️  В ПАПКЕ ПРОЕКТА НАХОДИТСЯ ФАЙЛ glass.css
⚠️  НЕЙРОСЕТЬ ДОЛЖНА ИСПОЛЬЗОВАТЬ ЭТОТ ФАЙЛ БЕЗ ИЗМЕНЕНИЙ
⚠️  ПРИМЕНИТЬ ЭФФЕКТ КO ВСЕМ КАРТАМ, ВКЛАДКАМ, КНОПКАМ, ПОВЕРХНОСТЯМ
⚠️  ЗАПРЕТИТЬ ЛЮБЫЕ ОТСТУПЛЕНИЯ ОТ ЭТОГО ЭФФЕКТА
⚠️  НЕ ДОБАВЛЯТЬ СОБСТВЕННЫЕ CSS СТИЛИ ВМЕСТО glass.css

Параметры эффекта (если glass.css не хватает):
- backdrop-filter: blur(22px) saturate(150%)
- Полупрозрачность: rgba(255, 255, 255, 0.1) или rgba(0, 0, 0, 0.2)
- Border-radius: 13px (закруглённые углы)
- Box-shadow: лёгкая тень для глубины

ЛОГИКА ИНТЕРФЕЙСА:
- Простой и понятный для русского пользователя
- Все вкладки в нижней навигационной панели
- Быстрый доступ к основным функциям
- Нет усложнений и "излишеств"

═══════════════════════════════════════════════════════════════════════════════
  ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ
═══════════════════════════════════════════════════════════════════════════════

ВКЛАДКИ ПРИЛОЖЕНИЯ (9 ОСНОВНЫХ):

1️⃣  ГЛАВНАЯ (Home)
   - Время ближайшего намаза (большим шрифтом)
   - Список всех 5 намазов на день с временами (Фаджр, Зухр, Асир, Магриб, Иша)
   - Название текущего времени молитвы (если сейчас время намаза)
   - Быстрые кнопки: "Мой вопрос AI", "Мой компас на киблу"
   - Исламский календарь (текущая дата)

2️⃣  AI ПОМОЩНИК (Chat)
   - Интеграция с Polza AI API
   - Помощник специализирован на исламских знаниях
   - НОВАЯ СЕССИЯ ДЛЯ КАЖДОГО ДИАЛОГА (история не сохраняется)
   - Ввод текста и отправка сообщения
   - Ответ от AI в виде текста
   - Дизайн как обычный чат-мессенджер (пузырьки сообщений)

3️⃣  КОРАН (Quran)
   - Список всех 114 сур (глав)
   - Поиск по названию суры
   - Открытие суры → список аятов (стихов)
   - Отображение текста аята на арабском и русском переводе
   - Закладки (избранное) — сохранение любимых сур/аятов

4️⃣  ДУА (Prayers)
   - Готовые дуа по категориям (утренние, вечерние, перед едой, в беде и тд)
   - ВОЗМОЖНОСТЬ ДОБАВЛЯТЬ СВОИ ДУА
   - Каждое дуа: название, текст на арабском, перевод на русском
   - Кнопка "Добавить в мои дуа" (сохранить для текущего пользователя)
   - Для своих дуа: название + текст + дата добавления

5️⃣  ИСЛАМСКИЙ КАЛЕНДАРЬ (Calendar)
   - Текущая дата (Григорианская + Исламская)
   - Дни до Рамадана / дни Рамадана (если идёт)
   - Дни до Хаджа
   - Важные исламские даты (Ид аль-Фитр, Ид аль-Адха, Мавлид и тд)
   - История (когда был последний Рамадан, когда будет следующий)

6️⃣  ИНФОРМАЦИЯ О ХАДЖЕ (Hajj)
   - Этапы хаджа (Ihram, Tawaf, Sa'i и тд)
   - Описание каждого этапа на русском
   - Важные места (Кааба, гора Арафат, Муздалифа)
   - Требования к паломнику
   - История и значение хаджа
   - Расписание современного хаджа (если доступно)

7️⃣  КОМПАС НА КИБЛУ (Qibla Compass)
   - АВТОМАТИЧЕСКОЕ ОПРЕДЕЛЕНИЕ ЛОКАЦИИ (требуется разрешение браузера)
   - Стрелка компаса, указывающая на киблу
   - Направление: Северо-запад / Запад / и тд (текст)
   - Угол в градусах (например, "45°" или просто стрелка)
   - Кнопка "Обновить локацию"
   - Работает offline (расчёты на клиенте)

8️⃣  ИСЛАМСКИЕ ЗНАНИЯ (Knowledge)
   - Категории: Основы веры, Столпы ислама, Правила намаза и тд
   - Статьи/текст по каждой теме
   - Просто и понятно для русского пользователя
   - Без сложной терминологии (или с объяснениями)

9️⃣  НАСТРОЙКИ (Settings)
   - Выбор локации / города для времени намазов (по умолчанию Москва)
   - Выбор школы ислама (малики, ханафи, шафиит, ханбали) — влияет на время намазов
   - Язык приложения (русский / английский)
   - Тема (светлая / тёмная) — по умолчанию тёмная
   - Включение/отключение уведомлений о намазах
   - Часовой пояс (автоматический или вручную)
   - Профиль: имя, фото (если нужно)

═══════════════════════════════════════════════════════════════════════════════
  СИСТЕМА НАПОМИНАНИЙ И УВЕДОМЛЕНИЙ (TELEGRAM BOT)
═══════════════════════════════════════════════════════════════════════════════

TELEGRAM БОТ:
- Использовать Telegraf на Node.js
- Проверка каждую минуту (node-cron: '* * * * *')
- Когда наступает время намаза → отправить сообщение в чат

СООБЩЕНИЕ О НАМАЗЕ:
"🕌 Наступило время намаза [ИМЯ]

Время: [ЧАС:МИНУТЫ]
Дуа перед молитвой готово ➜ [кнопка]
Открыть приложение ➜ [кнопка web_app]"

ДОПОЛНИТЕЛЬНЫЕ КОМАНДЫ БОТА:
/start — Приветствие + кнопка открыть приложение
/time — Время следующего намаза
/help — Справка
/settings — Открыть настройки приложения

═══════════════════════════════════════════════════════════════════════════════
  МНОГОПОЛЬЗОВАТЕЛЬСКАЯ СИСТЕМА
═══════════════════════════════════════════════════════════════════════════════

АУТЕНТИФИКАЦИЯ:
- По Telegram initData (как в трекере привычек)
- HMAC-SHA256 подпись с "WebAppData" ключом
- Проверка на Backend

СОХРАНЕНИЕ ДАННЫХ ПО ПОЛЬЗОВАТЕЛЮ (по telegram_id):
- Каждый пользователь (мама, папа, ты) имеет отдельный аккаунт
- Сохраняется: избранные суры, свои дуа, локация, язык, тема
- История диалогов с AI НЕ сохраняется (новая сессия каждый раз)
- Уведомления отправляются каждому пользователю независимо

ТАБЛИЦЫ БД (ПРИМЕРНО):
- users (telegram_id, first_name, last_name, city, school, language, theme, timezone)
- favourite_quran (user_id, sura_id, ayat_id)
- user_dua (user_id, title, text_ar, text_ru, created_at)
- prayer_times (user_id, date, fajr_time, zuhr_time, asr_time, maghrib_time, isha_time)

═══════════════════════════════════════════════════════════════════════════════
  ИСТОЧНИКИ ДАННЫХ И API
═══════════════════════════════════════════════════════════════════════════════

1. ВРЕМЯ НАМАЗОВ:
   API: Aladhan API (https://aladhan.com/api)
   Запрос: /timingsByCity?city=Moscow&country=Russia&method=2
   Обновление: раз в день (или кэширование)

2. AI ПОМОЩНИК:
   API: Polza AI
   Система: "Ты — исламский помощник. Отвечай на вопросы про ислам."
   (Пользователь подставит свой API ключ в .env)

3. ГЕОЛОКАЦИЯ (Компас киблы):
   Использовать: Geolocation API браузера (window.navigator.geolocation)
   Расчёт киблы: формула на JS (не требует API)

4. ДАННЫЕ КОРАНА:
   Источник: JSON-файл или API (например, quran-api.com)
   Хранить: в БД или как статические файлы

5. ИСЛАМСКИЕ ЗНАНИЯ:
   Источник: текстовая база (вписать вручную или использовать источник)
